# K-means-cpp

Консольная программа на C++ для кластеризации данных методом **K-means** (k-средних).
Управление — через текстовое меню на базе библиотеки `ncurses`, данные загружаются из CSV-файла.

## О проекте

K-means — алгоритм машинного обучения без учителя: он разбивает набор объектов на `k` групп (кластеров)
так, чтобы объекты внутри одной группы были как можно ближе друг к другу, а группы — как можно дальше друг от друга.

Программа пишется как учебная реализация алгоритма «с нуля», без сторонних библиотек для машинного обучения.

## Требования

- **ОС:** Linux (разработка велась на Ubuntu)
- **Компилятор:** `g++`
- **Библиотека:** `ncurses` с поддержкой широких символов (`ncursesw`)
- **Локаль:** `ru_RU.UTF-8`

Установка зависимостей на Ubuntu / Debian:

```bash
sudo apt update
sudo apt install g++ libncurses-dev locales
```

Если локаль `ru_RU.UTF-8` ещё не сгенерирована в системе:

```bash
sudo locale-gen ru_RU.UTF-8
sudo update-locale
```

Проверить, что локаль доступна, можно командой `locale -a | grep ru_RU`.

## Формат входных данных

Данные подаются в виде CSV-файла:

- значения разделены запятой `,`;
- **первая строка — заголовок** (названия признаков);
- каждая следующая строка — один пример (объект), каждое значение — числовой признак;
- дробная часть отделяется **точкой**;
- все значения должны быть числами, иначе программа сообщит об ошибке чтения.

Пример (фрагмент набора данных Iris):

```csv
SepalLengthCm,SepalWidthCm,PetalLengthCm,PetalWidthCm
5.1,3.5,1.4,0.2
4.9,3.0,1.4,0.2
4.7,3.2,1.3,0.2
4.6,3.1,1.5,0.2
```

При чтении к каждому примеру автоматически добавляется первая колонка с порядковым номером точки.
